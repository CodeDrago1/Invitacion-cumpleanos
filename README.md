# Invitación de cumpleaños

Invitación web interactiva y responsive, pensada principalmente para visualizarse desde teléfonos móviles y compartirse mediante un enlace.

## Estado — v0.1

- Pantalla de apertura tipo mensaje recibido.
- Transición de entrada.
- Diseño responsive mobile-first.
- Cuenta regresiva funcional con fecha provisional.
- Secciones preparadas para fotografías, datos del evento, ubicación y confirmación.
- Animaciones al hacer scroll.

## Estructura

- `index.html` — estructura de la invitación.
- `css/style.css` — diseño y responsive.
- `js/main.js` — apertura, animaciones y contador.
- `assets/` — se utilizará para imágenes y audio cuando se definan los recursos finales.

Los datos actuales son demostrativos y serán sustituidos por la información real del evento.
